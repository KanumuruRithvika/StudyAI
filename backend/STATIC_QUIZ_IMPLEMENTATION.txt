🚀 HOW TO USE - 3 SIMPLE STEPS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Run the System
───────────────────
$ python main.py

Or with a specific topic:
$ python main.py "Learn Python Dictionaries"

Or test LangSmith:
$ python main.py --test-langsmith


STEP 2: Answer Interactive Prompts
───────────────────────────────────
[PLANNER generates plan]
[TASK generates 3 tasks]
[QUIZ asks 5 questions]

Question 1 - Your answer (a/b/c/d): b
Question 2 - Your answer (a/b/c/d): a
Question 3 - Your answer (a/b/c/d): c
Question 4 - Your answer (a/b/c/d): d
Question 5 - Your answer (a/b/c/d): b

[EVALUATOR asks for score]

Enter your score (e.g., 4 for 4/5): 4

[ADAPTIVE asks about follow-up]

Would you like a follow-up quiz on weak topics? (yes/no): yes

[If YES: Loop back to QUIZ with weak topics]
[If NO: Workflow ends]


STEP 3: View in LangSmith
────────────────────────
Dashboard opens automatically!

1. Find your run (at the top)
2. Click QUIZ_AGENT to see:
   ✅ All 5 questions loaded
   ✅ Your 5 answers recorded
   
3. Click EVALUATOR_AGENT to see:
   ✅ Your score (e.g., "4/5")
   ✅ Strong/weak topics extracted
   
4. Click ADAPTIVE_AGENT to see:
   ✅ Your follow-up decision (yes/no)
   ✅ Recommendations provided

🔄 WORKFLOW FLOW WITH STATIC QUIZZES
═══════════════════════════════════════════════════════════════════════════════

Entry
  ↓
[PLANNER_AGENT] → Generate 3-day plan
  ↓
[TASK_AGENT] × 3 → Generate tasks 1, 2, 3
  ↓
[QUIZ_AGENT] → Load STATIC_QUIZ_INITIAL (5 questions)
  ↓
YOU ANSWER → Input a/b/c/d for Q1-Q5
  ↓
[EVALUATOR_AGENT] → You enter score (0-5)
  ↓
Analyze topics → LLM identifies strong/weak
  ↓
[ADAPTIVE_AGENT] → Show recommendations
  ↓
YOU DECIDE → Follow-up quiz? (yes/no)
  ↓
    ├─→ YES → [QUIZ_AGENT] Load STATIC_QUIZ_WEAK_TOPICS (loop back)
    │         → YOU ANSWER → [EVALUATOR_AGENT] → [ADAPTIVE_AGENT]
    │
    └─→ NO → [WORKFLOW ENDS] → Dashboard opens
